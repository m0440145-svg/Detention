# تمرين الاستعادة الربع سنوي

1. خادم معزول داخل المملكة، دون البريد أو SMS أو webhooks. تعطيل كل Integration قبل تشغيل scheduler.
2. تحقق من SHA-256 ثم فك AES-GCM عبر `deploy/encrypt_stream.py decrypt` إلى قاعدة اختبار منفصلة. لا تستخدم قاعدة الإنتاج ولا خيار clean عليها.
3. `pgbackrest --stanza=ehsan --type=time --target='<timestamp>' restore` للنسخة مع WAL؛ هذا الأمر يُنفذ فقط في مجلد PostgreSQL المعزول. يلزم تثبيت pgBackRest داخل خادم PostgreSQL وتوصيل إعداداته قبل استخدامه.
4. استعادة media ومفتاح DATA_ENCRYPTION_KEY من خزنة مستقلة. تحقق أن ملفات التخزين مشفرة وأن القراءة عبر التطبيق فقط ممكنة.
5. تشغيل الهجرات والفحص وسلاسل تدقيق كل المراسلات، مطابقة عدد السجلات وأحدث حدث قبل حادث الاختبار وبصمات المرفقات.
6. سجل وقت بداية/نهاية التمرين. القبول: RPO ≤1 ساعة، RTO ≤4 ساعات. نجاح ملفات الإعداد لا يثبت تحقيق هذه القيم.
7. سجل المحضر والتاريخ والمنفذ ونتائج المطابقة والمخالفات. تُحفظ النتيجة في موقع منفصل عن النسخة الاحتياطية.

لا يوجد تمرين إنتاج منفذ في هذه الجلسة؛ لم يُقدم خادم سعودي أو نسخ إنتاج.
