# منصة إدارة المهام ومتابعة القرارات

**جمعية الإحسان للخدمات الاجتماعية ببريدة** — تطبيق عربي RTL مبني على Django وDjango REST Framework، مع PostgreSQL للإنتاج وSQLite للتطوير المحلي.

يوفر تسجيل الدخول بالبريد أو الجوال أو اسم المستخدم، 6 أدوار، وحدات متعددة لكل موظف، وإسنادًا لمسؤول رئيسي ومشاركين أو لجميع موظفي وحدة أو عدة وحدات. بيانات المستخدمين والمهام محفوظة في قاعدة البيانات، والصلاحيات تطبق في الخادم وAPI.

## الوظائف

- لوحات حسب نطاق الدور، مؤشرات تنفيذ واعتماد والتزام، وأداء وحدات ورسوم لتوزيع التكليفات حسب الموظف.
- مهام وحقول التكليف والسرية والنتيجة ومؤشر النجاح، مهام فرعية وإنجاز تلقائي اختياري.
- سير حالات مقيد. الإنجاز 100% يطلب الاعتماد؛ رئيس الوحدة أو إدارة مخولة تعتمد أو تعيد المهمة. يمنع الاعتماد الذاتي للمسؤول الرئيسي.
- عوائق، طلب تدخل، توثيق المعالجة، تعليقات متسلسلة وردود وإشارات لموظفين ووحدات.
- ملفات محمية، تنزيل بعد التحقق من الصلاحية، فحص الحجم والامتداد والتوقيع، ورفض وحدات ماكرو Office.
- محرك متابعة وتصعيد قابل للضبط، تنبيهات داخل التطبيق، وتصعيد أسرع للمهام الحرجة.
- اجتماعات وقرارات ومرفقات، قرار واحد إلى عدة مهام، نسب تنفيذ واعتماد منفصلة.
- 12 تقريرًا، فلاتر وبحث، Excel وCSV، وطباعة وحفظ PDF من المتصفح.
- إدارة الموظفين والوحدات والأدوار، إعدادات حالات وأولويات وأنواع المهام.
- سجل نشاط يمنع تعديله وحذفه عبر التطبيق، ومحفزات قاعدة البيانات لحماية السجل.

## التشغيل المحلي

Python 3.12 أو أحدث ضمن إصدارات Django المدعومة. من مجلد المستودع:

```bash
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.lock
```

اضبط `DEBUG=1` في بيئة التطوير، ثم:

```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

افتح `http://127.0.0.1:8000/`. الحساب الذي ينشئه `createsuperuser` يحصل على دور مسؤول النظام. لإنشاء بيانات تجريبية، اضبط `DEMO_PASSWORD` إلى كلمة مرور خاصة من 12 حرفًا على الأقل ثم نفذ:

```bash
python manage.py seed_demo
```

ينشئ الأمر 16 وحدة و19 حسابًا و30 مهمة و3 قرارات، بأسماء **تجريبية** لا تمثل موظفي الجمعية. لا يغير البيانات عند تشغيله مجددًا. الحسابات: `demo-admin`، المدير `demo-01`، رئيس وحدة `demo-03`، الموظف `demo-09`، والمراقب `demo-viewer`. كلمة المرور هي قيمة `DEMO_PASSWORD` التي تختارها؛ لا توجد كلمة مرور إنتاجية مضمنة.

لتشغيل التصعيد والتذكير محليًا في عملية ثانية:

```bash
python manage.py run_scheduler
```

أو شغل `python manage.py evaluate_tasks` من المجدول الخاص بالخادم. لا تشغل نسختين من المجدول في الوقت نفسه.

## النشر على خادم

يتطلب Docker Compose، نطاقًا يشير إلى الخادم، وإتاحة المنفذين 80 و443. لا تشغّل بيانات تجريبية على بيانات الجمعية الفعلية.

1. انسخ `.env.example` إلى `.env`، واضبط النطاق والمضيفين و`CSRF_TRUSTED_ORIGINS`.
2. أنشئ `SECRET_KEY` طويلًا وعشوائيًا وكلمة مرور مستقلة لقاعدة البيانات. لا تحفظ `.env` في Git.
3. شغل `docker compose up --build -d`.
4. أنشئ المسؤول: `docker compose exec web python manage.py createsuperuser`.
5. Caddy يجهز HTTPS، وتبدأ خدمة المجدول تلقائيًا. قاعدة البيانات والمنفذ 8000 لا ينشران على الإنترنت.

تطبق الترحيلات وتجميع الملفات الثابتة عند تشغيل الخدمة. ملفات المستخدمين وPostgreSQL محفوظة في volumes. خط Tajawal مضمن محليًا بترخيص OFL؛ لا يعتمد التشغيل على Google Fonts.

للنسخ الاحتياطي: `sh deploy/backup.sh`. جدوله يوميًا من نظام تشغيل الخادم، واحفظ نسخة مشفرة خارج الخادم. تعليمات الاستعادة في [دليل التشغيل](docs/OPERATIONS.md).

## التحقق

```bash
python manage.py test --verbosity 2
python manage.py check
python manage.py makemigrations --check --dry-run
node --check core/static/core/app.js
```

الفحوص تغطي دورة إنشاء → إسناد → تنبيه → تحديث → مرفق → عائق → رد ومعالجة → 100% → اعتماد → إغلاق → مؤشر وتقرير وسجل، وتحويل القرار إلى مهام. تشمل أيضًا رفض الوصول عبر API والملفات، مستخدم العرض، CSRF، الإسناد متعدد الوحدات، المهام الفرعية، تكرار المجدول، وحماية السجل.

GitHub Actions مهيأ لتشغيل نفس الفحوص على PostgreSQL 16. نتائج الاختبارات المحلية وتحديد ما لم يُختبر في [سجل التحقق](docs/VERIFICATION.md).

## حدود التشغيل والتكامل

- لم يتم توفير خادم أو نطاق للمشروع في هذه المحادثة؛ المستودع يحتوي التطبيق وتجهيزات النشر، وليس موقعًا منشورًا.
- البريد وWhatsApp وOTP والتوقيع والتقويم وتكامل الأنظمة الخارجية لم تفعل. المطلوب في الملف يجعل البريد وWhatsApp وOTP مراحل لاحقة؛ نقاط التوسع موثقة في [المعمارية](docs/ARCHITECTURE.md).
- PDF ينتج عبر وظيفة الطباعة في المتصفح، وليس محرك PDF خادميًا. لا توجد خدمة مكافحة فيروسات مدمجة؛ الفحص الحالي بنيوي، ويُنصح بتوصيل ماسح ملفات قبل استقبال ملفات من أطراف خارجية.
- سجلات التطبيق محمية من الكتابة والحذف. مسؤول قاعدة البيانات القادر على تغيير المخطط يستطيع تعطيل المحفزات؛ الأرشفة الخارجية غير القابلة للتغيير تتطلب تخزينًا مستقلًا.
- واجهات API تعتمد جلسات Django وCSRF. التكامل بين الخوادم يحتاج اعتمادًا منفصلًا مضبوط النطاق قبل إتاحة API لطرف خارجي.
- إنجاز المهمة الرئيسي في الوضع التلقائي هو المتوسط المتساوي للمهام الفرعية. إنجاز القرار هو متوسط تنفيذ مهامه، والاعتماد هو نسبة مهامه المغلقة. إسناد وحدة يحفظ قائمة الموظفين النشطين وقت الإسناد، ولا يضيف الموظفين المنضمين لاحقًا تلقائيًا.
