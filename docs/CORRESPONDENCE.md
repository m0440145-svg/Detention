## الوظائف المنفذة

أنواع المراسلات الستة، التسلسل الهجري الذري، دليل الجهات، القوالب بإصدارات، تصنيف واستبقاء، منع تكرار الوارد وتنبيه التشابه، Metadata وملخص ومشروع/برنامج، تصنيف السرية والوصول الخادمي، الإحالات المتوازية والمتسلسلة، المهمة المرتبطة والتزامن، اعتماد متعدد المستويات وسبب الرفض، تفويض بوقت، إغلاق استثنائي مسبب للتنفيذي، تعليق وانتظار مع SLA، قوائم بحث وفلاتر محفوظة، OCR محلي بكل الصفحات مع الثقة والاقتراحات، تدقيق غير قابل للتعديل ومقارنة النسخ.

MFA/TOTP ومنع replay وتقييد المحاولات، OAuth2/PKCE/scopes، OIDC مسبق الربط، خمول الجلسة وشبكات الإدارة، AES256-GCM للمرفقات، فحص ClamAV مغلق عند فشل الماسح، API call log، مصدر HR موحد وتعطيل عند إنهاء الخدمة، import_mail dry-run وحفظ IDs والأرقام والمرفقات والبصمات، outbox/idempotency/retry/HMAC، إرسال Graph واستقبال البريد عبر موصل، تفضيلات SMS/digest، تقارير PDF/A وExcel وجدولة، سجل معالجة وطلبات خصوصية، لجنة استبقاء وحجز قانوني ومحضر وإثبات إتلاف نسخ الأرشيف قبل التنفيذ، طلب توقيع PAdES وتحقق من الشهادة/TSA/PDF/A والملف/الموقّعين، QR عام محدود، إبطال وإعادة اعتماد، أربعة أنواع لوحات وخيارات لغة.

## بدء التطوير والتحقق

```bash
DEBUG=1 python manage.py migrate
DEBUG=1 python manage.py test
DEBUG=1 python manage.py makemigrations --check --dry-run
DEBUG=1 python scripts/verify_scheduler_runtime.py
DEBUG=1 python manage.py verify_mail_audit
```

الإنتاج يتطلب SECRET_KEY وPostgreSQL ومفتاح DATA_ENCRYPTION_KEY جديداً 32 بايت base64 ومستضيفاً سعودياً وتشفير قاعدة/قرص وخزنة. DEBUG ليس بديلاً عن سياسة الإنتاج. لا تضع مفاتيح في Git ولا تنشر MEDIA_URL.

## حدود التنفيذ الفعلي

| المجال | الموجود في الكود | ما لم يحدث فعلياً |
|---|---|---|
| هوية/MFA | TOTP وOIDC وOAuth2/PKCE | لم يربط AD أو نفاذ أو SAML broker لحساب الجمعية |
| Snso | HR callback/poll وimport مع dry-run | لا API/تصدير تاريخي رسمي مقدم، لم ترحل سجلات الجمعية |
| بريد/SMS/DMS | Graph وgateway contracts/outbox وإثبات callback | لا إرسال/استقبال مؤسسي أو إتلاف إنتاج دون حساب المورد وتفويض |
| توقيع | PDF/A، PAdES validator، شهادات/TSA/QR، سياسة ترتيب | لا شهادة مرخصة أو مزود مربوط؛ رفض النتائج الناقصة مقصود |
| ملفات | AES256-GCM وفحص ClamAV إلزامي | لا إثبات تشفير قرص DB أو scanner محدث لدى مستضيف سعودي |
| تشغيل | scheduler، backup مشفر، إعداد full/incr/WAL، دليل restore | لا خادم سعودي تم توفيره أو تمرين استعادة/حمل/اختراق إنتاج |
| تجربة المستخدم | RTL/LTR، HTML labels/focus/mobile CSS، أربع لوحات | لا اختبار خمسة موظفين أو قارئ شاشة أو مراجعة مرئية جوال فعلية |
| سياسات | مصفوفة تنفيذ وقواعد وإجراءات ومحاضر | أمثلة demo لا تصبح سياسة مجلس أو مدد NCAR معتمدة |

هذه الحدود لا تُغلق بعبارة «تم بالكامل». مراجعة كل بند في ACCEPTANCE تربط الدليل البرمجي بالتفعيل والتسليم المطلوب من الجمعية.
