# الاتصالات الإدارية ضمن منصة الإحسان

الوحدة الجديدة جزء من التطبيق نفسه، بنفس حسابات Django والوحدات والجلسات. قوائمها: لوحة الاتصالات، بانتظار إجرائي، الوارد، الصادر، الأرشيف، البحث المحفوظ، التقارير والضبط. منصة المهام والقرارات السابقة باقية وتُستخدم لتنفيذ الإحالات.

## الوظائف المنفذة

- أنواع IN/OUT/INT/CIR/DEC/RPL، دليل جهات موحد، تصنيفات هرمية وتوجيه افتراضي، بيانات الخطاب الأصلي، تصنيف السرية، أولوية، جهة/منصة المصدر، قرار ومراسلة مرتبطان.
- ترقيم ذري لكل نوع وسنة هجرية بتقويم أم القرى عبر HijriDate 2.6.0؛ الوارد عند التسجيل، والصادر بعد اكتمال الاعتماد وإثبات التوقيع الداخلي. الرقم الملغى لا يعاد استخدامه. منع ازدواج الوارد للجهة والرقم الخارجي بقيد قاعدة بيانات.
- قوالب من نص آمن ومتغيرات محددة، وإصدارات مستقلة دون تنفيذ HTML أو كود مستخدم. تحرير القالب القائم محظور؛ الإصدار الجديد سجل مستقل.
- مسارات اعتماد مرتبة حسب الأدوار، بمرجع مصفوفة الصلاحيات؛ نسخة المسار تحفظ في المراسلة عند التقديم. يمنع الاعتماد الذاتي وتجاوز المستوى، والرفض بسبب إلزامي. التفويض بمدة زمنية وأدوار محددة.
- إحالات متوازية أو متسلسلة وتأشيرة إلزامية؛ لا تنجز المرحلة المتسلسلة قبل السابقة. إتمام الوارد يتطلب إنهاء الفروع التنفيذية. إحالة واحدة تتحول إلى مهمة واحدة، ويزامن المجدول إغلاق المهمة المعتمد مع إنجاز الإحالة.
- رفع ملفات عبر الخادم، تحقق الحجم والنوع والبنية، بصمة SHA-256، تخزين خاص وتنزيل بعد التحقق من الصلاحيات. تعديل النسخة الصادرة النهائية ومرفقاتها محظور.
- سرية مستقلة عن دور المستخدم: مسؤول النظام لا يقرأ المحتوى؛ المقيد والسري يحتاجان إدراجًا مباشرًا. لا تنسخ عناوين أو نصوص المراسلات المحمية إلى المهمة، ويظهر رابطها فقط للمصرح له. تصدير CSV والطباعة والتنزيل ممنوعة للمقيد والسري. منع خدمة الطباعة لا يمنع تصوير الشاشة أو طباعة محتوى سبق عرضه من أدوات المتصفح.
- سجل أحداث لكل مراسلة: المستخدم، الوقت، IP، السبب، قبل/بعد، سلسلة بصمات. حماية ORM ومحفزات SQLite/PostgreSQL تمنع التعديل والحذف. السلسلة تكشف العبث، ولا تعوض التخزين الخارجي غير القابل للكتابة أو حماية مسؤول قاعدة البيانات.
- SLA بأيام/ساعات العمل الفعلية حسب الأولوية، عطلة الجمعة/السبت والإجازات القابلة للإدخال، مهلة الجهة الأقصر، تذكير وتصعيد بنسب قابلة للضبط، إيقاف العداد لانتظار جهة خارجية بمبرر، وتمديد بمبرر. يعاد ضبط التنبيه عند تمديد الاستحقاق؛ يظل تكرار الدورات اليومية منضبطًا بمفتاح فريد.
- بحث النص الأساسي والمستخرج مع تطبيع الهمزات والتشكيل والتاء المربوطة والألف المقصورة، فلاتر وبحث محفوظ لكل مستخدم. الاستعلام يبدأ بنطاق الصلاحيات ولا يكشف عنوانًا غير مصرح.
- استخراج نص محلي غير متزامن للصور/PDF باستخدام Tesseract ara+eng وPoppler؛ TXT/CSV يستخرجان كنص دون ادعاء OCR أو نسبة ثقة. أول خمس صفحات PDF كحد أقصى، نتائج آلية قابلة للمراجعة لا تغير البيانات التعريفية صامتًا، واللغة العربية الناقصة تؤدي إلى فشل ظاهر. حاوية Docker تضم الأدوات؛ لم يجر اختبار بصري لدقة OCR العربي على صور فعلية في هذه البيئة.
- تقرير سجل CSV ضمن الصلاحيات، ملخص حسب الوحدة، وإجراءات جماعية ذرية للتذكير الداخلي والأرشفة. الأرشفة تحتاج فئة استبقاء معتمدة بمرجع؛ لا يوجد إتلاف فعلي أو حذف تلقائي.

## مصفوفة مختصرة

| الدور | المراسلات | التنفيذ والاعتماد | الضبط |
|---|---|---|---|
| مسؤول النظام | لا يقرأ المحتوى | ممنوع | SLA، المراجع، الأدوار، التفويض والقوالب |
| التنفيذي / المساعد | كل العادي والداخلي؛ المحمي بقائمة مباشرة | إدارة ضمن الرؤية، والاعتماد في المستوى المخصص فقط | لا |
| رئيس الوحدة | وحدته ومراسلاته المباشرة؛ المحمي بقائمة مباشرة | إدارة الوحدة والاعتماد عند مستواه | لا |
| الموظف | مسوداته وتكليفاته وقائمة التصريح | التحرير والمعالجة المكلف بها؛ تسجيل/إحالة الوارد إذا مُنح صلاحية الاتصالات | القوالب إذا منح الصلاحية |
| المدقق/العرض | نطاق الوحدة والقائمة المباشرة | قراءة فقط | لا |
| المجلس | ما أضيف لقائمة وصوله فقط | قراءة فقط | لا |

## مسارات الحالات

الوارد: مسجل → محال/قيد المعالجة → انتظار جهة خارجية (وقف SLA)/استئناف → منجز → مؤرشف؛ أو إلغاء بمبرر.

الصادر: مسودة → تدقيق → اعتماد مرتب → توقيع → مُصدر برقم → مرسل بدليل يدوي → مستلم بدليل → مؤرشف؛ أو إعادة للتصحيح/إلغاء بمبرر.

الإثبات الداخلي متاح فقط للمذكرات والتعاميم، ويصرح صراحة بأنه ليس شهادة رقمية. إصدار OUT/RPL/DEC بالتوقيع الخارجي محجوب إلى أن يربط مزود موثق؛ لا يسجل النظام توقيعًا ناجحًا من نص حر أو صورة أو رقم OTP غير متحقق.

## API

مسار CRUD: `/api/communications/` (GET/POST/PATCH؛ لا حذف). مسارات السجل: transition، attachments، referrals، complete-referral، convert-to-task، extend-due، extract_text، extraction، audit. قوائم المراجع: `/api/communications-master/`. الإجراء الجماعي: `/api/communications-bulk/` مع mail_ids/action/reason.

الجلسة والصلاحيات وCSRF تستخدم نظام الدخول السابق في `/api/auth/`. هذه مصادقة جلسات للخادم نفسه، وليست تنفيذ OAuth2 للتكاملات الخارجية. لا توجد مفاتيح تكامل أو استدعاءات بريد/Snso صامتة.

## تشغيل واختبار

نفذ migrate ثم شغل web وscheduler. المجدول الحالي يفحص قواعد المهام والمراسلات كل دقيقة وينفذ دفعة استخراج محدودة. حاوية المجدول تقرأ نفس media volume دون صلاحية كتابة. `seed_demo` يضيف 8 مراسلات وقوالب ومسارات تجريبية ومهمة مرتبطة؛ المستخدمون والوحدات لا تُكرر. البيانات الأصلية السابقة (30 مهمة) باقية، مع مهمة واحدة جديدة ناشئة عن إحالة.

اختبارات القبول تغطي: الرقم والتكرار، مسار الاعتماد ومنع الذات والتجاوز، رفض التوقيع الخارجي الوهمي، منع العنوان السري في HTML/API/البحث والتقرير، بصمة الملف والتنزيل، منع تعديل النسخة النهائية، الإحالات المتوازية والمتسلسلة، المهمة الواحدة ومزامنتها، عدم تسريب النص المحمي في المهمة، العطل والإجازات ووقف SLA، حدود 80/100/150% وعدم التكرار، سجل البصمات ومحفزات الحماية، سلطة إعدادات الخادم، الاستبقاء، عرض جميع الشاشات، استخراج النص والفشل الصريح عند غياب العربية، والإجراء الجماعي الذري.

## ما يحتاج بيانات أو خدمة خارجية قبل اكتمال المتطلبات التشغيلية

هذا تنفيذ أساس وظيفي للوحدة، وليس إثبات اكتمال جميع بنود برومبت المصدر أو امتثال قانوني معتمد.

| البند | الحالة وما يلزم |
|---|---|
| Snso والموارد البشرية كمصدر حقيقة | لا مصدر مربوط. يلزم API/تصدير رسمي ومطابقة employee_number/unit والمعرفات؛ لا تم ترحيل بيانات أو إحداث تعطيل حسابات فعلية. نعيد استخدام المستخدمين الحاليين مؤقتًا دون تكرارهم. |
| ترحيل التاريخ والمرفقات | يلزم جرد وتصدير Snso، آخر أرقام كل نوع/سنة، مطابقة الحقول والبصمات وتشغيل عينة قبل التحويل. لا تعلن هجرة ناجحة دون مصدر ومطابقة. |
| توقيع PAdES / نفاذ / QR | يلزم مزود مرخص وربط تحقق وطابع زمني. التوقيع الخارجي محجوب؛ لا QR أو شهادة وهمية. |
| البريد المؤسسي وSMS وتقارير مجدولة | يلزم مزود وربط وتفويض إرسال؛ التنبيهات الحالية داخل التطبيق فقط. |
| OAuth2/Webhooks/SSO/MFA | تحتاج منظومة هوية وصلاحيات تكامل مستقلة ومراجعة أمنية؛ ليست بدائل عن مصادقة الجلسة الحالية. MFA متطلب قبل الاستخدام التشغيلي الحساس. |
| PDF/A، ختم/توقيع رسمي ومحرر غني | الحالي نص عربي آمن ونسخة طباعة؛ حفظ PDF من المتصفح لا يثبت PDF/A. |
| فحص البرمجيات الضارة | الفحص الحالي بنيوي؛ يلزم ماسح ملفات قبل استقبال مرفقات غير موثوقة في الإنتاج. |
| إتلاف موثق/طلبات أصحاب البيانات | الأرشفة والاستبقاء موجودان؛ موافقات لجنة الإتلاف وإجراءات الطلبات تحتاج اعتماد الجمعية وتنفيذ مرحلة مستقلة قبل أي إتلاف. |
| تطبيق ECC/حماية البيانات/الوثائق | يتطلب مصفوفة مواد من النسخ النافذة ومراجعة اختصاصية؛ أمثلة الاستبقاء والمسارات ليست سياسة الجمعية المعتمدة. |
| استضافة سعودية/تشفير التخزين/الاستعادة/اختراق | تحتاج استضافة فعلية وإعدادات تخزين ومفاتيح ونسخ مشفرة واختبار استعادة واختراق؛ نشر المعاينة لا يثبت ذلك. |

## خطة الربط والإطلاق

1. اعتماد مصفوفة الصلاحيات والتقويم وفئات الاستبقاء، وتوفير استضافة Django/PostgreSQL داخل المملكة ومزود الهوية وفحص الملفات.
2. جرد Snso وتصديره؛ عينة ترحيل تتضمن التحقق من الأرقام والمرفقات ثم خطة تحويل ورجوع. يمنع إطلاق تسلسل رسمي جديد قبل تثبيت آخر الأرقام التاريخية.
3. ربط مصدر الموظفين بدل الإدخال المزدوج، والبريد ومزود التوقيع. اختبار تعاقد API والوصول السري والفشل وإعادة المحاولة.
4. تشغيل إدارة تجريبية ثم توسيع تدريجي. قياس جودة OCR على عينات عربية فعلية، واختبار الجوال وقابلية الاستخدام وWCAG، واستعادة واختراق قبل بيانات الجمعية.
