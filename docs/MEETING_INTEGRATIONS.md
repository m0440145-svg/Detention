# تكاملات الاجتماعات والتشغيل

لا أسرار في المستودع أو HTML أو السجلات. الحالة الافتراضية `ready_to_connect`، والتحكم الإداري لا يسمح بـ`works`. الجاهزية تنتج عن اختبار فعلي مثبت مع البيئة والتوقيت، وتصبح صلاحية الاختبار قديمة بعد 30 يومًا. اكتمال طلب تفعيل لا يفعّل الموصل.

## عقد Parq المقترح — لا توثيق معتمد من المزود

مسارات API لا تُخمن؛ تضبط من عقد المزود. جميع الروابط مقيدة بـHTTPS و`ehsan.parq.sa` والمنفذ 443، بلا إعادة توجيه. طلب التوقيع يحمل معرف الطلب والمحضر والإصدار وبصمة المحتوى والموقعين دون هوية وطنية. مفتاح Idempotency ثابت لطلب كل إصدار ويحتفظ به حتى عند فشل الشبكة. المهلة اتصال 5 ثوانٍ وقراءة 20 ثانية. لا إعادة محاولة عمياء؛ يعاد نفس المفتاح بعد التحقق من الحالة لدى المزود.

الرؤوس `X-Ehsan-Timestamp` و`X-Ehsan-Signature` توقع `timestamp + '.' + raw_body` بـHMAC-SHA256. رد callback يقبل خلال 300 ثانية فقط، ومعرف حدث فريد ومحتوى ثابت عند الإعادة، وبصمة مطابقة وجميع الموقعين المطلوبين عند الاكتمال. النتيجة تضم summary_url وverification_url وسجل أحداث آمن من المزود. لا تولد شهادة رسمية محليًا. تحديد `PARQ_ENVIRONMENT=production` وحده لا يكفي؛ يلزم الاختبار وبيانات البيئة والعقد.

## ترحيل وتشغيل

1. نسخة احتياطية واختبار استرجاع على بيئة الجهة. تطبيق migrations مع PostgreSQL قبل تشغيل الخادم الجديد. اختبارات CI تفحص المخطط ومحفزات الثبات؛ لا تستخدم rollback لحذف بيانات تصويت أو محاضر حقيقية.
2. إعداد Django/HTTPS وPostgreSQL ومخزن خاص مشفر ومفاتيح ثابتة مع خطة تدوير، وفحص الملفات الإنتاجي الموجود. لا seed_demo على الإنتاج.
3. تشغيل `run_scheduler` تحت خدمة مستقلة وفق دليل التشغيل الحالي. يتابع التذكيرات الداخلية وتصعيد المهام ومهل القرارات والامتثال والتوصيات، ويمنع تكرار نفس التنبيه. تسجيله لا يمثل إرسال قناة خارجية.
4. `certify_meeting_workflows --owner ADMIN_USERNAME` يسجل اختبارًا داخليًا معزولًا فقط. اختبر بعد ذلك جميع المسارات بأدوار الجهة وعلى الهاتف والقلم وقارئ الشاشة، وفشل الشبكة والتزامن والاستعادة.
5. أضف الموصلات المتبقية من عقود رسمية ومخططات موثقة. لكل موصل اختبار sandbox ثم إنتاج، وتقليل بيانات، ومالك تقني وDPA وسجل فشل وإعادة محاولة آمنة. سجل الحالة والمتطلبات موجود لاستقبال هذه الإضافات.

المعاينة الحالية ليست استضافة Django ولا تحقق تشغيل الإنتاج على نطاق الجمعية؛ نشرها لا يغير DNS أو بيانات الجهة.
