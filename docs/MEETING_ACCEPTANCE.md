## الأدلة

- `meetinghub/test_workflows.py`: 48 اختبارًا إضافيًا؛ الوظائف المحمية، الاقتراع، النصاب، السرية المتغيرة، المحاضر، رفع الملفات، واجهات API، الانتخابات، OTP، HMAC ومنع التكرار، الساعات، الخدمات، المصادر، المحتوى والحجز والإتلاف.
- المجموعة الكاملة تشمل الاختبارات السابقة للوحدات والمهام والقرارات والاتصالات. نتيجة SQLite النهائية وتحقق PostgreSQL مسجلة في GitHub Actions للإصدار المرفوع.
- `manage.py check` و`makemigrations --check --dry-run`، وفحص صياغة JavaScript.
- حماية DB للتعديل والحذف تطبق على Event وإصدارات الأجندة والأهلية ونتائج التصويت والمحاضر والتوقيعات والختم والردود الانتخابية وإصدارات الإعدادات وفترات الحضور.

## حدود التسليم

الموقع المستضاف الحالي معاينة HTML خاصة للمالك من قاعدة عرض معزولة؛ نماذج الحفظ والمصادقة والإرسال غير تشغيلية فيه. الخادم الكامل يتطلب استضافة Django/PostgreSQL ومخزن ملفات دائم ومجدول وإعداد الأسرار وترحيلات هذه النسخة. لا مفاتيح مزود أو صلاحية DNS متاحة هنا. مراجعة العقد الرسمي وبيانات الإنتاج والاختبارات على الأجهزة ضرورية قبل إعلان تشغيل الإنتاج.

تصنيف صفحات الإجراءات: مساحة الاجتماع ↔ workflow handler/API ↔ إدارة الاجتماع أو عضو مؤهل؛ سجلات الحوكمة ↔ governance handler/API ↔ لجنة مخولة؛ الانتخابات ↔ election services/API ↔ أهلية مثبتة؛ المحتوى والسياسات ↔ platform handlers ↔ مسؤول النظام؛ التوقيع الرسمي ↔ Parq + HMAC ↔ مزود مهيأ ومختبر. تفاصيل الأفعال في ملفات الخدمة وسجل API.
