## تحويل الوارد المباشر إلى مهمة

- زر واضح في صفحة البريد الوارد لاختيار مسؤول التنفيذ والاستحقاق وسبب التكليف.
- متابعة الحالة ونسبة التنفيذ والاستحقاق والتأخر، مع فتح المهمة لتحديثها والعودة إلى البريد.
- إعادة استخدام مهمة الإحالة المفتوحة لمنع التكرار؛ تحقق الصلاحيات والسرية في الخادم وحفظ سجل التدقيق.
- واجهة API تدعم التحويل المباشر وبيانات المتابعة مع الحفاظ على تحويل الإحالات السابق.
